# Multi-Asset Statistical Arbitrage

Basket statistical arbitrage via regularized regression, nonlinear extensions, and a low-latency C++ execution engine.

**This repository is built incrementally across sessions.** Each session completes one Part of [`PLAN.md`](PLAN.md), commits it, and writes a [`HANDOFF.md`](HANDOFF.md) briefing the next session. This top-level README is completed in the final Part (reproducibility manual); until then it is intentionally brief.

## Quickstart
```bash
# 1. Bootstrap toolchain (idempotent; safe to re-run)
./environment/setup.sh

# 2. Verify environment
./environment/check.sh

# 3. Build & test the C++ engine (from Part 3 onward)
cmake -S src -B build && cmake --build build -j2

# 4. Build the report (canonical LaTeX + sandbox HTML preview)
python3 report/build_report.py
```

## Key environment facts (full map: `environment/env_map.md`)
- Only pypi + GitHub are reachable → **real market data comes from GitHub-hosted datasets**; no Yahoo/stooq/Nasdaq at runtime.
- No TeX engine installable → the report is **canonical LaTeX** (`report/report.tex`) plus a self-contained HTML preview; the PDF compiles wherever a TeX engine exists.
- C++ engine is **dependency-free at build time** (vendored Eigen or hand-rolled linear algebra).

## Repository layout
```
environment/   bootstrap + checks + env map + data-source candidates
scripts/       Python: data wrangling, statistical tests, plotting (NOT the strategy core)
src/           C++ engine: data/ model/ signal/ portfolio/ engine/ (Part 3+)
test/          C++ unit tests
bench/         C++ microbenchmarks (vector vs deque, SoA vs AoS, cache misses)
report/        LaTeX report + build driver
data/          raw + processed market data (git-ignored)
results/       every number/figure/table, generated by code (git-ignored except tracked summaries)
PLAN.md        master execution plan (13 parts)
HANDOFF.md     handoff for the next session (rewritten each Part)
```

## Rules
- No result in the report without a significance test, OOS validation, and cost adjustment.
- The report is **built**, not hand-typed for numbers — `report/build_report.py` regenerates figures/tables from `results/`.
- Walk-forward, lookahead-free, gross **and** net-of-cost everywhere.
- C++ is the simulation core; Python is research/plotting only.
